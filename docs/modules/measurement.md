# Measurement

Question: **Under exactly which structural conditions do we test each GrammarCell?**

`derive_operations(cell, structural_conditions)` formalises structural requirements without producing English. `build_measurement_opportunities` creates stable `OPP_…` records whose identity excludes lexical content, generator, folds, and KC policy.

Predicate-class contrasts make the central dependence explicit: a lexical present polar question requires DO-support and inversion, while the corresponding copular question requires inversion only.
