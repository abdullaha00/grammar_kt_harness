\section{Evidence Retained for the Reported Runs}

The archived run directories retain resolved configurations, clean source
commit identifiers and digests, reuse boundaries, stage summaries, prompts,
raw and parsed model responses, validation decisions, Q-matrices, simulated
event tables, fitted-model predictions, and metric summaries.  The primary
run and each policy variant use five declared simulation seeds.  Human
evaluation is not part of the present evidence; adding it would require a
predeclared sample, qualified annotators, instructions, adjudication,
agreement measures, and uncertainty reporting.
