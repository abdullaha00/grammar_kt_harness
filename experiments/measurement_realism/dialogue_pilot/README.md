# Dialogue continuum pilot

This directory freezes a **zero-call** pilot for studying the tradeoff between
ecological plausibility and grammatical measurement precision. Four selected
GrammarCells are each crossed with five planned response formats, for 20
matched opportunity slots. No opportunity, critic judgment, human judgment, or
learner response is generated by the checked-in plan.

## Artifacts

- `preregistration.md`: scientific questions, invariants, analyses, and gates;
- `human_expert_validation_protocol.md`: future expert, platform, learner, and
  error-realism evidence requirements;
- `config.yaml`: machine-readable frozen choices;
- `build_plan.py`: deterministic selection and request builder;
- `selected_cells.json`: frozen four-cell/20-slot plan;
- `generation_requests.jsonl`: four future call inputs with calls disabled;
- `prompts/`: future generation and independent-critic prompts;
- `schemas/`: exact generated-family and critic-judgment schemas;
- `analyze_dialogue_pilot.py`: separate-dimension analysis of future judgments;
- `manifest.json`: hashes and zero-call evidence boundary.

## Replay the plan

```bash
.venv/bin/python experiments/measurement_realism/dialogue_pilot/build_plan.py
```

The builder refuses to overwrite a changed frozen output. A successful replay
prints `live_model_calls_made: 0`.

## Analyze future critic judgments

After a separately authorized and fully preserved generation/critique stage:

```bash
.venv/bin/python \
  experiments/measurement_realism/dialogue_pilot/analyze_dialogue_pilot.py \
  --judgments PATH/critic_judgments.jsonl \
  --output PATH/analysis.json
```

Complete analysis requires 100 rows: 20 opportunities × five independent role
lenses. `--allow-incomplete` exists only for pipeline development and any such
output must be labeled incomplete. The analyzer produces distributions,
matched deltas, direction checks, and exact disagreement IDs; it deliberately
does not produce a scalar realism score.

## Current evidence boundary

This directory demonstrates a deterministic and auditable pilot design. It is
not evidence that dialogue is more realistic, that any item is deployable, or
that synthetic errors resemble human errors. Those claims require the future
validation protocol.
